# UI Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add golden-path UI tests for the web app (Playwright, mocked backend) and fill gaps in the mobile app's existing RNTL test suite.

**Architecture:** Web tests use Playwright with `page.route()` to mock tRPC HTTP batch requests and REST file endpoints — no real API/worker/Redis needed. Mobile tests extend the existing `jest-expo` + React Native Testing Library setup in `apps/mobile/__tests__/`, reusing `fixtures.ts` and `test-utils.tsx`. The web scan test asserts the mutation fires and the UI transitions to its pending state; Inngest-Realtime progress visualization is stubbed by mocking `useJobProgress` via a Playwright init script that overrides the Inngest token endpoint.

**Tech Stack:** `@playwright/test` (web), `jest-expo` + `@testing-library/react-native` (mobile, existing), shared fixtures data.

**Spec reference:** `docs/superpowers/specs/2026-04-15-ui-tests-design.md`. Note: the spec mentioned tRPC SSE for `onTaskProgress`, but the web actually uses Inngest Realtime via `useJobProgress`. Task 11 handles this correctly.

## Task 4: Mock tRPC HTTP batch handlers

**Background:** `@trpc/react-query` uses HTTP batch link by default. Requests look like:
`GET  /trpc/photos.photos,photos.folders?batch=1&input=<url-encoded-json>`
`POST /trpc/photos.scan?batch=1` (mutations)

Response shape for a batch of N procedures is an array of N `{ result: { data: <value> } }` objects, wrapped in superjson if `transformer: superjson` is used (it is, per `apps/api/src/trpc/trpc.ts` — worker assumes this). Check `apps/web/src/main.tsx` or `App.tsx` for the actual trpc client config.

**Files:**

- [ ] **Step 2: Create handlers module**

```ts
import type { Page, Route } from "@playwright/test";
import { FIXTURE_PHOTOS, FIXTURE_FOLDERS, searchPhotosByQuery } from "./photos";
import { TINY_WEBP_BYTES, TINY_JPEG_BYTES } from "./images";

// Parses tRPC batch URL, returns array of { path, input }
function parseTrpcBatchRequest(url: URL, method: string, postData: string | null) {
	const pathSegments = url.pathname.replace(/^\/trpc\//, "").split(",");
	const inputParam = url.searchParams.get("input");
	const inputs: Record<string, unknown> = inputParam ? JSON.parse(inputParam) : {};
	const body: Record<string, unknown> = method === "POST" && postData ? JSON.parse(postData) : {};
	return pathSegments.map((path, i) => ({
		path,
		input: (inputs[i.toString()] as any)?.json ?? body[i.toString()] ?? null,
	}));
}

type Handler = (input: unknown) => unknown;

export type HandlerOverrides = Partial<Record<string, Handler>>;

export const DEFAULT_HANDLERS: Record<string, Handler> = {
	"photos.folders": () => FIXTURE_FOLDERS,
	"photos.photos": (_input) => ({ photos: FIXTURE_PHOTOS }),
	"photos.searchPhotos": (input: any) => ({
		photos: searchPhotosByQuery(input?.query ?? ""),
	}),
	"photos.scan": () => ({ success: true, jobId: "test-job-123" }),
	"photos.realtimeToken": () => ({ token: "test-token-xyz" }),
};

export async function installTrpcHandlers(page: Page, overrides: HandlerOverrides = {}) {
	const handlers = { ...DEFAULT_HANDLERS, ...overrides };

	await page.route(/\/trpc\//, async (route: Route) => {
		const req = route.request();
		const url = new URL(req.url());
		const calls = parseTrpcBatchRequest(url, req.method(), req.postData());
		const results = calls.map(({ path, input }) => {
			const handler = handlers[path];
			if (!handler) {
				return { error: { json: { message: `No handler for ${path}`, code: -32000 } } };
			}
			return { result: { data: { json: handler(input) } } };
		});
		await route.fulfill({
			status: 200,
			contentType: "application/json",
			body: JSON.stringify(results),
		});
	});

	// REST endpoints for thumbnails and full images
	await page.route(/\/api\/photos\/\d+\/thumbnail\//, (route) =>
		route.fulfill({ status: 200, contentType: "image/webp", body: TINY_WEBP_BYTES }),
	);
	await page.route(/\/api\/photos\/\d+\/file/, (route) =>
		route.fulfill({ status: 200, contentType: "image/jpeg", body: TINY_JPEG_BYTES }),
	);

	// Block Inngest Realtime SSE; the hook is quiescent without a subscription
	await page.route(/inngest\.com|\/api\/inngest/, (route) =>
		route.fulfill({ status: 204, body: "" }),
	);
}
```

**Note:** The `{json: ...}` wrapping assumes the client uses superjson transformer. If Step 1 revealed no transformer, change `data: { json: handler(input) }` to `data: handler(input)` and parse inputs without `.json`.
